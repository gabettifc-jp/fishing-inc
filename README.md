### 第19版で変えたところ

- **パークの段数を軸ごとに変えた。**上限3を一律にやめ、**無限段の軸を二つ**置いた
  （クーラーの売値・自動の竿の本数。10章で「天井なし」と決まっている二つ）
- **発散しない条件 α<1** を7章に置いた。値段の伸び率をどこまで下げてよいかがこれで決まる
- **図鑑の売値を +0.5%／種 → +5%／種**（全40種で +200%）
- **所持金の持ち越しを、持ち越し枠の六つ目に統合**
- **「戻り倍率（毎周 約5.6倍）」を10章の目標に追加。**移動手段の値段から逆算して出た
- 釣り糸を3段から一回きり2個に作り直した

**まだ決まっていないこと：**釣り場が何周目に開くか（2章と10章が食い違っている）。`open.md` 参照。
