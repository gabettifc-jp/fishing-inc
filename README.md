# fishing-inc

釣りで金を増やし、道具を買い、伸びが鈍ったら転生してパークを取りに行くインクリメンタル（仮題「釣りインクリメンタル」）。

## 今どの段階か

**仕様書は実装に渡せる状態。まだ何も実装していない。**

`spec.md` は第8版。gamedev の `flow.md` 段階3の四区画で照らすと、こうなる。

| 区画 | 状態 |
|---|---|
| A. 遊びの設計 | **埋まっている** |
| B. 画面の設計 | **画面Aは埋まった。BとCは未着手** |
| C. 入出力の設計 | **埋まっている** |
| D. 初期値 | **埋まっている** |

四つとも埋まったので、実装に渡せる。画面BとCは25回しか見ない画面なので、
画面Aの見た目が決まってから詰める。
