# fishing-inc

釣りで金を増やし、道具を買い、伸びが鈍ったら転生してパークを取りに行くインクリメンタル（仮題「釣りインクリメンタル」）。

## 今どの段階か

**仕様書はあるが、まだ何も実装していない。**

`spec.md` は第6版。遊びの設計（核・波・転生・譜面・魚40種・パーク・演出七段）は埋まっている。
一方で **画面の設計と入出力の設計が空**なので、gamedev の `flow.md` の基準では実装に渡せる状態ではない。

- 埋まっている … A. 遊びの設計
- 空 … B. 画面の設計／C. 入出力の設計／D. 初期値

## builds の最新

まだ無い。実装していないため。
