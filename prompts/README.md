# prompts/

Claude Codeに投げた指示文を、日付付きで残す。

## 決まり

- 一回の指示につき一ファイル。`YYYY-MM-DD-（何を作らせたか）.md`
- 投げた文をそのまま貼る。後から整えない
- 返ってきた「勝手に決めた点」は `open.md` に写す

## 型

`gamedev/templates/prompt.md` の五つを毎回入れる。

## 中身

| ファイル | 何を作らせたか |
| --- | --- |
| `2026-08-18-stage1.md` | 第一段。仕様書第17版の 0〜12章を全部。画面A・B・C・図鑑、つまみ、測る仕組み |
| `2026-08-18-stage2.md` | 第二段。第18版に差し替えて数値を合わせる |
