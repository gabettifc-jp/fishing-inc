# ジャンルシート：インクリメンタル（fishing-inc）

**埋めるのはここだけ。**インクリメンタル固有の問いで、汎用シート（00〜09）に行き先が無いもの。

**相場は写さない。**`gamedev/templates/sheets/genre/incremental.md` を見る。
相場は 00〜09 の問いに対する答えの目安なので、答えは 00〜09 のシートに書く。
ここに写すと、相場が二か所になる。

## 固有の問い

| 問い | 答え | 相場 | 外すと何が起きるか |
|---|---|---|---|
| **最初の報酬までは何分か** | | **最初の報酬ループで生きるか死ぬかが決まる。**理解できてから報われるまでの間を詰める。最初の伸びを早くして、手応えのある演出を付ける | **最初の1時間で離脱する。**掴む前に閉じられる |
| **放置（オフライン進行）はあるか。あるなら戻ったときにどう見せるか** | | **あるとは限らない。**Egg, Inc. は放置の影響を減らすため2時間で切っている。**無い作りに「放置できない」と文句が出た例がある。**入れるなら、戻ったときに適用するか捨てるかを選ばせる作りもある | 「放置ゲーなのに放置できない」と言われる／戻ったときに何が起きたか分からない |
