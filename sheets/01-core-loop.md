**どのゲームにも要る。**秒から分の単位で繰り返すもの。

| 問い | 答え | 根拠 |
|---|---|---|
| 一回のループで、プレイヤーは何をするか | 投げる → 2〜8秒待つ → ヒット → 短いリズムゲー → 釣果が決まる（3章） | 2〔0章の核から〕 |
| 一回は何秒か | およそ5〜10秒。一周で四十〜五十回ほど（3章） | 3〔実測：10章11で **6.1／6.7／7.4秒**（釣り場ごと）と出た〕**★答えが古い**（「5〜10秒」は測る前の値） |
| 一回ごとに何がもらえるか | 魚（お金）。未発見なら図鑑に記録される（3章・9章） | 2〔0章の核から〕 |
| **それがもらえたと、画面のどこで分かるか** | 押した瞬間、符号が一瞬ふくらんで戻る＋高い短い音。当たり／外しで画面の端が緑／赤に光る（8章0）。魚が上がったら中央に魚の名前と格に応じた演出（8章1・9章）。**いくらかは、その場では出していない**（クーラーに溜めて「売る」でまとめて金になる。9章） | 1〔相場：釣りゲー01「それがもらえたと…」＋音ゲー08「成功したとき…」〕／3〔実測 2026-08-20〕。**★答えが古い**（第26版で釣果の札に**魚の絵・名前・一匹の値段**を出すようにした） |
| もらったものを何に使うか | 道具（餌・釣り糸・リール・クーラー・竿）と移動手段を買う（7章） | 2〔7章の成長の三層から〕 |
| **一回ごとに判断はあるか。何を賭けるか** | 一回ごとの賭け → 連続。完璧で+1、そこそこで維持、逃すと切れる。自動の竿は伸ばせない | 2〔3章の完璧／そこそこ／逃すの三段と、2章の連続ボーナスから〕 |
| 一回ごとに結果が変わるか。何で変わるか | 変わる。待ち時間（2〜8秒）、掛かる魚の格、格ごとの譜面、符号一個ずつの判定（当たり／かすり／外し）（3章） | 2〔3章の乱数（待ち・格・譜面・判定）から〕 |
| **これを何百回繰り返しても飽きないと言える理由** | 面白さを二つに分けてある。リズムゲーは自分の竿がずっと手動なので消えない。「何が掛かるか分からない」は格が音で分かっても種類は上がるまで不明なので最後まで効く（3章） | 3〔未〕**これは仮説であって根拠ではない。**`hypotheses.md` に在るが、通しで確かめていない |

> **周期が長すぎると飽き、短すぎると単調になる。**
> 「最も時間を費やす30秒から1分は、本当に楽しいか」から始める。
