# 01 コアループ

**どのゲームにも要る。**秒から分の単位で繰り返すもの。

| 問い | 答え |
|---|---|
| 一回のループで、プレイヤーは何をするか | 投げる → 2〜8秒待つ → ヒット → 短いリズムゲー → 釣果が決まる（3章） |
| 一回は何秒か | およそ5〜10秒。一周で四十〜五十回ほど（3章） |
| 一回ごとに何がもらえるか | 魚（お金）。未発見なら図鑑に記録される（3章・9章） |
| **それがもらえたと、画面のどこで分かるか** | |
| もらったものを何に使うか | 道具（餌・釣り糸・リール・クーラー・竿）と移動手段を買う（7章） |
| **一回ごとに判断はあるか。何を賭けるか** | 一回ごとの賭け → 連続。完璧で+1、そこそこで維持、逃すと切れる。自動の竿は伸ばせない |
| 一回ごとに結果が変わるか。何で変わるか | 変わる。待ち時間（2〜8秒）、掛かる魚の格、格ごとの譜面、符号一個ずつの判定（当たり／かすり／外し）（3章） |
| **これを何百回繰り返しても飽きないと言える理由** | 面白さを二つに分けてある。リズムゲーは自分の竿がずっと手動なので消えない。「何が掛かるか分からない」は格が音で分かっても種類は上がるまで不明なので最後まで効く（3章） |

> **周期が長すぎると飽き、短すぎると単調になる。**
> 「最も時間を費やす30秒から1分は、本当に楽しいか」から始める。
