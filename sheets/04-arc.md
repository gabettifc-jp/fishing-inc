# 04 アーク

**ループとアークは違う。**

- **ループ**は何回繰り返しても面白い（積む、跳ぶ、撃つ）
- **アーク**は繰り返せない（物語を読む、新しい場所が開く、一度きりの解放）

**アークをループの代わりに置くと、尽きた瞬間に穴が空く。**

尽きるものを一つずつ書く。

| 尽きるもの | 何回で尽きるか | 尽きるのは通しのどのあたりか | **尽きた後に何が始まるか** |
|---|---|---|---|
| 釣り場の解放（移動手段） | 8回（釣り場8個。4章） | 8つ目が開くのは12〜15周目（10章の目標） |  |
| 自動化の節目（開く型1〜6） | 6回（7章） | 約4周に一回（2章） |  |
| パーク | 29個（7章・10章） |  |  |
| 魚（図鑑） | 40種（5章） |  |  |

> **右端の列が空のまま実装すると、そこから先が退屈になる。**
> fishing-inc の「移動手段を買う」は8回で尽き、その後が空だった。
