# 04 アーク

**ループとアークは違う。**

- **ループ**は何回繰り返しても面白い（積む、跳ぶ、撃つ）
- **アーク**は繰り返せない（物語を読む、新しい場所が開く、一度きりの解放）

**アークをループの代わりに置くと、尽きた瞬間に穴が空く。**

| 問い | 答え |
|---|---|
| **難しさはどこで上がるか** | |

| 尽きるもの | 何回で尽きるか | 尽きるのは通しのどのあたりか | **尽きた後に何が始まるか** |
|---|---|---|---|
| 釣り場の解放（移動手段） | 8回（釣り場8個。4章） | 8つ目が開くのは12〜15周目（10章の目標） | **パークを狙う周になる**（第19版で決めた） |
| 自動化の節目 | 6回（7章。開く型1〜4＋竿の精度3段目・7段目） | 約4周に一回（2章） |  |
