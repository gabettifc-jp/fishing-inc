# 02 メタループ

**コアループの外側にある「なぜ繰り返すのか」の理由。何層あってもよい。**

各層について、次を埋める。**層の数だけ繰り返す。**

## 層（　　　　　）

| 問い | 答え |
|---|---|
| この層で、プレイヤーは何を目指すか | 一投を釣り上げて金にする（3章） |
| **一周（この層が一巡）は何分か** | およそ5〜10秒（3章） |
| 一巡すると何が変わるか | お金が増える。未発見なら図鑑が埋まる（3章・9章） |
| **一巡すると何が消えて、何が残るか** | 消えるものは無い。釣った魚はクーラーに溜まり、「売る」で金になる。未発見なら図鑑が埋まる（恒久。2章・9章） |
| **この層は何回巡ると尽きるか。尽きないか** | 尽きない（3章） |
| 尽きるなら、尽きた後は何の層が動くか | コア層の「尽きた後」→ 該当なし（尽きない層なので、空欄ではなかった） |

## 層（　　　　　）

| 問い | 答え |
|---|---|
| この層で、プレイヤーは何を目指すか | 転生通貨を得てパークを取る（0章・7章） |
| **一周（この層が一巡）は何分か** | 1周目3分 → 25周目15分（2章） |
| 一巡すると何が変わるか | 道具は消える。パーク・釣り場の解放・図鑑は残る（2章・7章） |
| **一巡すると何が消えて、何が残るか** | **道具は消える**（持ち越し型のパークで一部を除く）。**パーク・釣り場の解放・図鑑は残る**（7章） |
| **この層は何回巡ると尽きるか。尽きないか** | 標準で25周前後。固定ではない（2章） |
| 尽きるなら、尽きた後は何の層が動くか | クラーケンを釣ったら終わり（2章） |

## 層の一覧

| 層 | 目指すもの | 一巡の長さ | 何回で尽きるか |
|---|---|---|---|
| コア | 一投を釣り上げて金にする | 5〜10秒 | 尽きない |
| メタ1 | 転生してパークを取る | 3分→15分 | 25周前後 |
| メタ2 | 移動手段を買って次の釣り場を開ける | 約3周に一回 | 8回 |

> **通しの時間を、層の長さと回数で割り算して確かめること。**
> 合わないなら、どこかの層が足りないか、多すぎる。
