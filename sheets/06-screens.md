# 06 画面

flow.md 段階3の **B. 画面の設計** の問いを、そのまま表にしたもの。内容は変えていない。

| 問い | 答え |
|---|---|
| **画面は何種類あるか。**それぞれ何をする画面か | 三つ。A＝釣り（道具屋を含む）、B＝転生、C＝釣り場選び。図鑑は画面を切り替えず上にかぶせ、閉じたら戻る（9章） |
| **画面はどう行き来するか。**どこからどこへ、何を押すと移るか | C 釣り場選び ⇄ A 釣り → B 転生 → C。AとCは行き来できる。Bは一方通行。図鑑はどの画面からでも開閉（9章） |
| **一番よく見る画面には、何がどこに置いてあるか。**上・下・左・右・中央に、それぞれ何があるか | 上端＝所持金・連続数・図鑑と転生のボタン。右＝道具屋（餌・糸・リール・クーラー・移動手段。竿はパークを取ってから）。中央から下＝水面と浮き。掛かったら中央に譜面の帯がポップ（9章） |
| 盤面があるなら、**一マスの大きさと、縦横のマス数** | マス目のゲームではない（9章「マス目のゲームではないので、譜面から逆算する」） |
| キャラや物の大きさは、マスに対して何倍か | マスではなく画素で決めている。浮き8、魚（雑魚）16、超大物は画面の6割、**譜面の帯540（20拍ぶん。符号数によらず一定）**、一拍27、短音27・長音54、カウントイン108、譜面の帯の高さ80、竿の先の太さ3（10章12。第20版） |
| **常に見えていなければならない数値は何か**（所持金、残量、進み具合） | 所持金、連続数。画面に余裕があれば転生時にもらえる量。出さないのは、いまどの釣り場にいるか（背景で分かる）／図鑑の進み具合（開いたときだけ）／自動化の状態（竿の絵で分かる）（9章） |
| 色は何段階使うか。何で色が変わるか | 段階の数は書かれていない。ドットの粒は大きくてよいが色は現代的に使ってよい。背景の彩度は抑える（予兆で画面全体が金色に振れるため）。譜面の帯だけは全釣り場で同じ色（9章・11章） |
| 参考にする画面があるなら、**実物を見て数字で書く**（「これを見て似せて」ではなく） | 参考にする画面 → 置いていない。10章12で画素を直接決めている |
