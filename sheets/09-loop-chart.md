# 09 周ごとの表

**メタループが何度も巡るゲームで、「何周目に何をするか」を書く表。**

03（ビートチャート）の縦軸は通しの時間で、これは一本道のゲームの型である。
繰り返しが主のゲームでは、体験の単位は「通しの3／4」ではなく「**15周目**」になる。
03 だけでは後半が書けないので、この表を足す。

> **右の三列（取る恒久の強化・新しいこと・次の周へ移る合図）が空いている行が、
> 遊ぶ人が何をすればいいか分からない周である。**

## 先に決めないと埋まらないこと

**表が埋まらないときは、たいてい表より上に穴がある。**先にここへ書き出す。

| # | 決めること | いまどうなっているか |
|---|---|---|
| 1 | 釣り場が何周目に開くか | **決めた。8つ目（深海）は20周目。**2章の「約3周に一回」を採る。開くのは 2・5・8・11・14・17・20周目。10章の目標「12〜15周目」を20周目に直す |
| 2 | 8つ全部が開いた後、毎周の目標は何か | **決めた。パークにする。**残っている高いパークと無限段の軸を「あと1個」として狙う。合図も前半と同じ形になる（前半＝次の移動手段が買えたら／後半＝次に狙うパークが買えたら） |
| 3 | パークを、どの周で取るか | **決めた。**停滞周は無限段を1〜2段、跳ね周は移動手段＋自動化の節目。値段はこの配置から逆算する（先に配って、あとで値段） |

## 空欄の読み方

| 列 | 空いていると何が起きるか |
|---|---|
| この周の目標 | **遊ぶ人が何をすればいいか分からない周。**ここが空の行が続くと、そこが退屈な時間帯になる |
| 開くもの | アークが尽きている周。`04-arc.md` の右端の列と同じ問い |
| 取る恒久の強化 | 何周目に何が取れるかが、**値段と式の割り算まかせ**になる。配ってから値段を逆算するほうが速い |
| 新しいこと | 退屈になる周 |
| 次の周へ移る合図 | **「いつ切り上げるか」が決まっていない。**測る側が仮定を置くしかなくなり、置き方で周数が何倍にも振れる |
