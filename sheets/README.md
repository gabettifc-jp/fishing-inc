## なぜ値を書かないか

**第一段（2026-08-18）はシートに値を写していた。**
そのまま仕様書が第30版まで進んだとき、**12件が古くなっていて、誰も気づかなかった。**

| シートに写していた値 | そのあいだに仕様書はこうなっていた |
|---|---|
| 一回は 5〜10秒 | **6.1／6.7／7.4秒**（釣り場ごと。3章・10章3） |
| 通しで 3〜4時間 | **1時間50分**（2章） |
| パーク29個・魚40種 | **43個・72種**（10章10・5章） |
| 押した瞬間は 2200Hz の一定音 | **押した音が旋律になる**（11章・第29版） |
| 長音は8割で離してよい | **7割5分**（3章・第25版） |
| 距離の上限は書かれていない | **入っている**（3章・第24版） |
| 判定に関わるものは光の線で見える | **押す位置に縮む輪**が入った（9章・第30版） |
| もらえたと分かるのは演出と数字 | **釣果の札**に絵・名前・一匹の値段（8章1・第26版） |

**古くなったのは、全部が値を写していた欄である。**
第三段（2026-08-21）で、値を消して**章の参照に置き換えた。**行き先だけなら古くならない。

> **だから版の番号も書かない。**
> 「第30版のまま止めてある」と断り書きを付けても、**古いことに変わりはなかった。**

## 何が見えるか

```
node ../gamedev/tools/check-sheets.mjs sheets
```

| 出るもの | 意味 |
|---|---|
| **行き先が無い** | **仕様書のどこにも入らなかった問い。**空欄と「仕様書に無い」を同じに数える |
| **根拠が空** | 答えたのに、なぜそうしたかが書かれていない問い |

**いま出るもの（2026-08-21）。**

| | 件数 | 中身 |
|---|---|---|
| 行き先が無い | **4** | 何で作るか（00）／一周は何分か（02。周では書いてあるが分では無い）／負けはあるか（05。勝ちだけ在る）／色は何段階か（06） |
| 根拠が空 | **6** | **02 のメタ2の層、まるごと。**第一段でも第二段でも飛ばしていた |
| **4〔置いただけ〕** | 14 | `open.md` 9節に一覧 |

> **この二つの数字が、シートを残している理由そのもの。**
> 仕様書は第30版まで書けていて章も揃っていたのに、
> 「押すタイミングの予告」が丸ごと落ちていた。**散文では気づけない。表の空欄は見える。**
