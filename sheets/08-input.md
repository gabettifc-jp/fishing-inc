# 08 入出力

flow.md 段階3の **C. 入出力の設計** の問いを、そのまま表にしたもの。内容は変えていない。

| 問い | 答え | 根拠 |
|---|---|---|
| **入力は何種類あるか**（押す、長押し、ドラッグ、キー） | 二種類だけ。単押しと押しっぱなし（3章） | 2〔3章から〕 |
| **何を押すと何が起きるか。**操作の一覧 | 譜面の符号に光の線が来たら押す。短点＝単押し、長点＝押しっぱなし（早く離したら外し）。道具屋は押すだけで買える。上端の図鑑と転生のボタン。画面Cで釣り場を押すとそこから始まってAへ（3章・9章） | 2〔3章・9章から〕 |
| 待ち時間や演出のあいだ、操作を受け付けるか | 演出七段のうち、釣り場が変わった（1〜2秒）・超大物が上がった（1秒）・自動化が開いた（2秒）・転生した は手を止める。魚が上がった・予兆が出た・桁が変わった は止めない（8章・10章13） | 2〔8章の演出七段から〕 |
| **絶対に止めてはいけない操作はどれか**（頻度の高いものは止めると累積で効く） | 魚が上がった演出。通しで千回近く来るので、0.2秒でも合計で数十秒を奪う（8章） | 2〔通しで千回近く来るという回数から導かれる〕 |
| 間違えて押したときに取り返しはつくか | 取り返し → 一回の外しでは失敗しない（外し5割で逃す、糸で8割まで）。ただし外した符号は取り返せない | 2〔3章の「逃す」割合から〕 |
| **判定や当たりの外で入力したら、何が起きるか** | 押した時刻は**一番近い符号に割り当てる**（3章）。**距離の上限は書かれていない。**余計に押した回数は、そのまま外しに数える（3章） | 1〔相場：音ゲー08「判定や当たりの外で…」＝**窓の外の入力は符号を消さない**〕。**★答えが古い**（距離の上限は第24版で入り、窓の外でも早い／遅いを出す） |
| **何も入力せずに通り過ぎたら、何が起きるか** | 外し（3章の判定表「大きく外した、または押さなかった」） | 2〔3章の判定表から〕 |
| **入力が競合したとき（直前の入力がまだ続いているとき）、どちらを取るか** | **同じ符号に二回押したら、先に押したほうを採る。**あとの押しは「余計に押した」に数える（3章） | **4〔置いただけ〕**相場も〔相場が取れなかった〕（rhythm.md） |
| **成功したとき／失敗したとき、それぞれ何が返るか（音・画面）。何段階の言葉で返すか** | 押した瞬間：符号が一瞬ふくらんで戻る＋2200Hz・35ミリ秒〔仮〕。当たり／外しで画面の端が緑／赤（8章0）。判定の言葉は**当たり／かすり／外しの三段**（3章） | 1〔相場：音ゲーの返しの三層〕／3〔実測 2026-08-20〕。**★答えが古い**（第29版で**押した音が旋律**になり、2200Hz の一定音ではなくなった） |
| **操作の成否に許容の幅は何段階か。幅はどれだけか** | **三段。**当たり ±60ミリ秒／かすり 60〜140ミリ秒／外し それ以外（3章・10章）。深い釣り場では要求精度が 1.0→0.35 に厳しくなり、リールの段で戻る。59段で天井の±120ミリ秒（10章） | 1〔相場：音ゲー08「操作の成否に許容の幅は…」＝最高判定 ±15〜30ms（競技系）／±40〜67ms（緩め）〕＋**4〔±60／±140 はその帯の中に置いただけ〕** |
| **外したとき、どちら向きに外したかを返すか** | **早い／遅いの方向だけ出す。ミリ秒は出さない**〔実測 2026-08-20〕。見本でミリ秒まで出したら邪魔だった | 1〔相場：最高判定とMISS以外の全判定で EARLY／LATE を出す〕／3〔実測 2026-08-20：ミリ秒まで出したら「ちょっとうざい」と出た〕 |
| **続けて操作を求めるとき、人が反応できる時間を空けているか** | 長音の帯は**離してよい位置（8割）までで描き**、残りの2割が離してから次を押す時間になる（9章「長音の帯の描き方」）。**それ以外の間隔についての規定は無い** | 3〔実測：余裕は **125ミリ秒**〕。**★答えが古い**（8割 → **7割5分**。第25版） |
| **押し続ける操作は、始まり・続き・終わりのどれで判定するか。許容はどれだけか** | **押し始めで判定する。**そのうえで長音の長さ（2拍＝0.5秒）の8割より早く離したら外しに落とす。遅く離すのは咎めない（3章） | 1〔相場：終わりの見方は三通りに割れる（外し一回ぶん／評価の頭打ち／罰なし）。**離しの許容は押しより緩いのが共通**〕／3〔実測〕。**★答えが古い**（8割 → 7割5分） |
| **判定に関わる操作が、プレイヤーに見えているか** | 見えている。**譜面が先に全部置いてあり、光の線が左から右へ流れる**（9章）。判定の目印も置く | 1〔相場：音ゲー08「判定に関わる操作が…」＋**縮む輪が符号に重なった瞬間が押す時**〕。**★答えが古い**（第30版で**押す位置に縮む輪**が入った） |
| **返しの音が、背景の音に埋もれないか** | **埋もれてもよい。**代わりに**BGMを入／切できる**（10章「BGMの入切」）〔実測 2026-08-20〕 | 3〔実測 2026-08-20：「BGMは埋もれてもいい。有り無しが切り替えできるといい」と出た〕 |
| **環境による遅れを見込むか** | 〔このゲームには要らない〕今回は調整しない（2026-08-20に相談して決めた）。較正を置かないので、機械ごとのずれはそのまま出る | 相談して決めた（2026-08-20）。**根拠は無いが、要らないと合意した** |
